궁금한 점

설치 파일을 켰더니 "Windows의 PC 보호" 창이 떠요

새로 나온 프로그램이라 윈도우가 아직 잘 모르는 앱으로 보고 띄우는 안내입니다. 창의 추가 정보를 누른 뒤 실행을 누르면 설치가 시작됩니다. 설치가 끝난 뒤 런처를 켤 때는 이 창이 다시 뜨지 않습니다.

무료인가요?

네. 런처와 트루먼 클라이언트는 무료입니다. 마인크래프트를 하려면 마인크래프트 계정이 필요합니다.

업데이트는 어떻게 하나요?

따로 할 것이 없습니다. 런처를 켜면 런처와 게임 파일을 최신 버전으로 맞춘 뒤 시작합니다.

지우려면 어떻게 하나요?

윈도우 설정 → 앱 → 설치된 앱에서 "트루먼 클라이언트"를 찾아 제거하세요. 게임 파일과 설정은 남겨 두므로, 필요 없으면 직접 지우면 됩니다.
